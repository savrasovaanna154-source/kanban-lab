### 3.2. E2E (Playwright)

**Файл:** `client/e2e/full-flow.spec.ts`
**Тестов:** 3
**Браузер:** Chromium

**Сценарии:**
1. Регистрация → вход → создание проекта → доска → карточка → проверка сохранения после reload
2. Защита: без токена редиректит на `/login`
3. Валидация: HTML-minLength для пароля

**Команда:** `cd client && npx playwright test`

**Сценарий:** до 200 виртуальных пользователей, 60 секунд

| Метрика | Значение |
|---|---|

| Checks passed | 100% (7660/7660) |

**Отчёт:** `loadtest/RESULTS.md`, `loadtest/summary.json`
