# Требования к системе «Kanban-доска»

## 1. Функциональные требования

### 1.1. Аутентификация и авторизация
- **FR-01.** Регистрация по email и паролю.
- **FR-02.** Вход в систему с выдачей JWT (access + refresh).
- **FR-03.** Выход (удаление токена на клиенте).
- **FR-04.** Роли пользователей: `admin`, `manager`, `developer`.
- **FR-05.** Разграничение прав по ролям на уровне API (HTTP 403 при недостатке прав).

### 1.2. Проекты
- **FR-06.** Создание проекта (владелец = текущий пользователь).
- **FR-07.** Редактирование проекта (owner, manager, admin).
- **FR-08.** Удаление проекта (manager, admin).
- **FR-09.** Список проектов пользователя.

### 1.3. Доски и колонки
- **FR-10.** Создание Kanban-доски внутри проекта.
- **FR-11.** Создание, переименование, удаление колонок.
- **FR-12.** Изменение порядка колонок.
- **FR-13.** WIP-лимит на колонку — блокировка перемещения карточки при превышении.

### 1.4. Карточки (задачи)
- **FR-14.** Создание, редактирование, удаление карточек.
- **FR-15.** Перемещение между колонками (drag-and-drop).
- **FR-16.** Назначение исполнителя.
- **FR-17.** Приоритет: `low`, `medium`, `high`, `critical`.
- **FR-18.** Дедлайн (дата).
- **FR-19.** Метки (labels).
- **FR-20.** Описание (Markdown).
- **FR-21.** Комментарии к карточке.
- **FR-22.** Вложения (опционально).

### 1.5. Поиск и фильтрация
- **FR-23.** Поиск по тексту (title + description).
- **FR-24.** Фильтр по исполнителю.
- **FR-25.** Фильтр по меткам.
- **FR-26.** Фильтр по приоритету.

### 1.6. Прочее
- **FR-27.** История действий (audit log).
- **FR-28.** Уведомления in-app (опционально).
- **FR-29.** Экспорт доски в JSON (опционально).

## 2. Нефункциональные требования

| ID | Требование | Метрика |
|---|---|---|
| NFR-01 | Время отклика API | < 200 мс (p95) при 1000 одновременных пользователях |
| NFR-02 | Объём данных | не менее 10 000 карточек |
| NFR-03 | Защита от XSS | санитайзинг + CSP-заголовки |
| NFR-04 | Защита от CSRF | токены для state-changing запросов |
| NFR-05 | Защита от SQL-инъекций | параметризованные запросы (Prisma) |
| NFR-06 | Хеширование паролей | bcrypt, cost ≥ 10 |
| NFR-07 | HTTPS | обязательно в production |
| NFR-08 | Доступность | 99.9% |
| NFR-09 | Кросс-браузерность | Chrome, Firefox, Edge |
| NFR-10 | Адаптивность | от 320 до 1920 px |
| NFR-11 | Покрытие тестами (строки) | ≥ 80% |
| NFR-12 | Покрытие тестами (ветви) | ≥ 70% |

## 3. Вне области (out of scope)

- Мобильные приложения (iOS/Android).
- Интеграции с внешними трекерами (Slack, Telegram, MS Teams).
- Полнотекстовый поиск с морфологией.
- Мультиязычность интерфейса.
